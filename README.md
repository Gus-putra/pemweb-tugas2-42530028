# Tugas 2 Pemrograman Web

## Katalog Buku RuangBaca

Aplikasi web katalog buku sederhana yang dibuat menggunakan Express.js, pola MVC, dan template engine EJS.

### Fitur
- Menampilkan daftar buku.
- Pencarian buku berdasarkan judul atau penulis menggunakan Query Parameter (`req.query`).
- Filter buku berdasarkan kategori.
- Menampilkan detail buku berdasarkan ID menggunakan Route Parameter (`req.params`).
- Menampilkan halaman ketika buku tidak ditemukan.
- Menggunakan EJS partials untuk navbar dan footer.
- Mengirim data dari controller ke template menggunakan `res.render()`.

### Teknologi
- Node.js
- Express.js
- EJS
- HTML dan CSS

### Cara Menjalankan
1. Pastikan Node.js sudah terinstal.
2. Jalankan `npm install`.
3. Jalankan `npm start`.
4. Buka `http://localhost:3000` di browser.
